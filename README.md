## eotp-e

end of track engineering project, 2026. private work, public page.

## what this is

a three month engineering project carried out with an industrial partner, rebuilding the control software of a precision assembly and measurement bench. the existing program was written more than a decade ago in a proprietary graphical environment, is no longer maintainable in house, and runs on hardware that has aged out. the work replaces it with a maintainable python application, on current hardware, and proves with measurements that the new bench performs at least as well as the one it replaces.

the partner, the product and the process are covered by a confidentiality agreement. nothing about them appears here, in any repository, or in any commit.

twelve weeks of build, four weeks of maintenance, a written report every week and a validation signed off before production hits deployment.
